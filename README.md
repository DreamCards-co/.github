# DreamCards-co/.github

The public profile of the DreamCards GitHub organization.

- `profile/README.md`: the text and banner shown on https://github.com/DreamCards-co.
- `profile/assets/`: light and dark banners, 2560 × 800, rendered from the brand repo (`DreamCards-co/brand`) with its fonts, logo, and hero washes.
- `avatar-500.png`: the organization avatar (the tangerine app icon). GitHub has no API for org avatars, so upload it in the organization settings.
